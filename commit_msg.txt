✨ Jules: Advanced Feature - Eco Mode

💡 The New Power: Added 'Eco Mode' to pause heavy background data fetching and disable CSS animations, saving battery and RAM.
⚙️ How It Works: Introduced a new dashSettings.ecoMode state variable. When true, applyEcoMode() clears intervals for news AutoRefresh and Torn tracker updates, and toggles an .eco-mode class on the document body.
🎨 UI Enhancements: Added a new toggle to the settings modal. Disables UI backdrop blurs when eco-mode is active.
🧪 Verification: Created eco_mode.test.js using JSDOM to verify the persistence logic and clearing of interval timers.
